# MAGAI Movies

מה נראה הערב? כתבו בקשה בשפה חופשית ("מותחן איכותי לערב זוגי, עד שעתיים, בלי אימה") וקבלו רשימת המלצות אישית ועשירה — פוסטרים, דירוגים, טריילרים וקישורים לנטפליקס — שנבנית דינמית מ-TMDB ומ-LLM, לא מרשימה קבועה מראש.

## איך זה עובד

1. הבקשה החופשית נשלחת לשרת ומפורשת ל־preferences מובנים (ז'אנרים, אורך מקסימלי, שנים, טון, קהל יעד) על ידי LLM (Anthropic או OpenAI).
2. ה-preferences מומרים לשאילתת `discover` אמיתית מול TMDB (לא סינון של רשימה קבועה).
3. לכל מועמד נטענים בנפרד: זמן ריצה, ז'אנרים, טריילר רשמי מיוטיוב (אם קיים), וזמינות מאומתת בנטפליקס בישראל (TMDB watch/providers, region `IL`).
4. אם מוגדר מפתח LLM — נכתבים תיאור עריכתי ו"למה זה מתאים לך" ייעודיים לכל סרט. אם לא, נבנה תיאור מבוסס-תבנית מהנתונים האמיתיים (עדיין דינמי, לא טקסט קבוע).
5. אם אין מפתח LLM בכלל, יש נפילה חכמה (heuristic) שמפרשת מילות מפתח בעברית/אנגלית — אך שאילתת TMDB עצמה תמיד אמיתית ודינמית.

## הרצה מקומית

```bash
cp .env.example .env.local
# מלאו לפחות את TMDB_API_KEY
npm install
npm run dev
```

פתחו את http://localhost:3000

## משתני סביבה נדרשים

ראו `.env.example`. בקצרה:

| משתנה | חובה? | מה זה |
| --- | --- | --- |
| `TMDB_API_KEY` | כן (או `TMDB_ACCESS_TOKEN`) | נתוני סרטים, פוסטרים, טריילרים, זמינות בנטפליקס |
| `ANTHROPIC_API_KEY` | מומלץ | פענוח הבקשה + כתיבה עריכתית באמצעות Claude |
| `OPENAI_API_KEY` | מומלץ (אלטרנטיבה) | אותו תפקיד, דרך OpenAI, אם אין מפתח Anthropic |
| `NEXT_PUBLIC_SITE_URL` | לא | לצורך מטא-דאטה ל-Open Graph; מתמלא אוטומטית ב-Vercel |

## פריסה ל-Vercel

1. ייבאו את הריפו ל-Vercel.
2. הגדירו את משתני הסביבה ב-Project Settings → Environment Variables (זהים לאלו ב-`.env.example`).
3. Deploy.

## מגבלות ה-MVP

- זמינות "נטפליקס" מאומתת רק כאשר TMDB (מבוסס JustWatch) מדווח על כך עבור אזור ישראל; כשלא מאומת, הכפתור פותח חיפוש בנטפליקס ומתויג בהתאם ("חפשו בנטפליקס"), ולא נטען כאילו הסרט זמין.
- אין קישור ישיר לעמוד הסרט בנטפליקס (Netflix לא חושפת API ציבורי לכך) — הפעולה תמיד עוברת דרך חיפוש בדומיין הרשמי של נטפליקס.
- תיאורי "למה זה מתאים לך" נכתבים ע"י LLM כשמוגדר מפתח; אחרת הם נבנים מתבנית דינמית המבוססת על הנתונים בפועל.
